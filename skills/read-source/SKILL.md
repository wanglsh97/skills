# Read Source

开始源码学习前，完整阅读并严格执行 [完整工作流](references/workflow.md)。不要只读摘要后自行简化流程。

必须遵守以下入口约束：

- 自动选择仓库当前最新 tag，不要求、询问或等待用户指定。选定后立即固定为完整 commit SHA；仓库没有有效 tag 时停止。
- tag 及其选择过程只用于内部确定源码快照。不得在阶段回复、阶段产物、最终文档、产物目录名或最终回复中展示 tag 名、tag 日期、选择规则、commit SHA 或任何版本锚点描述。
- 严格按宏观俯瞰、能力架构、章节化精读、Markdown 落盘与逐章复核四个阶段执行，不跳过、合并、调换或并行阶段。
- 每个阶段写入并检查产物；检查通过后立即更新 `manifest.md` 并自动进入下一阶段，不等待用户确认或交互。检查失败时留在当前阶段修正。
- 每个阶段都把直接结果写入当前工作目录的 `.read-source/<产物项目目录名>/temp/`；若基础项目目录已存在，新任务为目录名追加 `_YYYY-MM-DD` 后缀。只在最终产物完整通过复核后删除该 `temp` 目录，任务中断或校验失败时保留。
- 精读结论只使用当前 commit 的源码证据；证据不足时标为尚未确认，严禁猜测。
- 在文档中展示关键逻辑的最小源码节选或明确标注的逻辑缩减，保留原始符号和语义，禁止大篇幅复制。
- 最终产物直接写入当前工作目录的 `.read-source/<产物项目目录名>/`，并确保每个关键知识点都能映射到源码路径、符号和行号。
