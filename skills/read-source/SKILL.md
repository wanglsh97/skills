# Read Source

开始前完整阅读并严格执行 [完整工作流](references/workflow.md) 与 [项目类型精读策略](references/project-types.md)。不要只读摘要后自行简化流程。

严格按以下三步执行，不跳过、合并、调换或并行：

1. 读 README、依赖清单、`AGENTS.md`、`docs/` 等文档，定位项目类型。
2. 根据项目类型决定精读入口，先总体摸清对外核心方法、组件、命令或生成能力。
3. 结合这些核心能力深入源码，学习运行时架构并落盘学习笔记。

必须遵守：

- 默认阅读当前工作区源码；用户指定版本或 tag 时按其指定，并固定后只从该快照读取。
- 先定类型，再选入口，后追实现。不要按目录、文件或包名平铺阅读。
- 结论只使用当前源码证据；证据不足标为尚未确认，严禁猜测。
- 每个步骤写入产物并检查通过后再进入下一步；检查失败时留在当前步骤修正。
- 阶段产物写入 `.read-source/<产物项目目录名>/temp/`；最终产物写入 `.read-source/<产物项目目录名>/`。
- 在文档中只展示理解所需的最小源码节选，保留原始符号，禁止大篇幅复制。
- 用户只要求阅读或解释时，不修改被学习的源码仓库。
